# Ahmed Maged — Portfolio

Personal portfolio site built with Next.js, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Configured for Netlify with `@netlify/plugin-nextjs`. Push to the connected branch to deploy.

## Content

Edit [`content/site.ts`](content/site.ts) to update experience, projects, skills, and contact info.
